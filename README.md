# DescarteVivo

Um site simples e informativo que apresenta os pontos de coleta de **lixo eletrônico no Distrito Federal (DF)**.  
O objetivo é incentivar o descarte correto de resíduos eletrônicos e facilitar o acesso da população aos locais de coleta.

---

## 🚀 Tecnologias Utilizadas
- **HTML5** → Estrutura das páginas  
- **CSS3** → Estilização e layout responsivo  
- **JavaScript (JS)** → Interatividade e manipulação dinâmica dos dados
